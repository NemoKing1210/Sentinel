# Нативная достоверность WinUI 3 — дизайн

**Дата:** 2026-11-05
**Статус:** на согласование
**Версия:** 0.4.0 → 0.5.0
**План реализации:** [2026-11-05-winui-native-fidelity.md](../plans/2026-11-05-winui-native-fidelity.md)

## 1. Контекст

Sentinel — это Tauri 2 + React 19 приложение. В 0.4.0 интерфейс уже переведён на WinUI / Fluent Design: токены Fluent, Segoe UI Variable, официальные Fluent System Icons, оболочка с заголовком окна и левой панелью навигации, Fluent-кнопки, поля, переключатели, ComboBox, SelectorBar, InfoBar и карточки.

Запрос пользователя:

> «Неплохо, но всё ещё далеко до идеала. Дизайн стал ближе похож на WinUI, но не на 100%. А надо как максимально похоже на современные нативные приложения Windows 11».

Цель — убрать оставшиеся «веб-швы» и приблизить приложение к тому, что пользователь видит в Проводнике, Параметрах и приложениях на WinUI 3. Переписывать UI на XAML не нужно и не предлагается: работаем в текущем стеке Tauri + HTML/CSS, но используем нативные возможности окна и точные метрики Fluent.

## 4. Целевое состояние

1. **Окно как у нативного приложения.** На Windows 11 build ≥ 22000 включена Mica; на Windows 10 и при недоступности эффекта — непрозрачный Fluent-фон без просвета рабочего стола. У окна есть тень и скруглённые углы.
2. **Системный акцент.** Новый вариант `system` выбран по умолчанию. Цвет читается из ОС, обновляется при возврате фокуса в окно и имеет контрастный `on-accent`.
3. **Заголовок окна.** Кнопка навигации, кнопка «назад» на отчёте, корректная иконка restore, приглушение в неактивном окне, Fluent-подсказки.
4. **NavigationView.** 320 px / 48 px / оверлей, элементы 36 px, клавиатурная навигация, InfoBadge для счётчиков, сохранение выбранного элемента.
5. **Списки.** Один surface на список, разделители, hover, строки 64 px, действия справа.
6. **Настройки.** Заголовки секций вне карточек, строки 64 px, без флагов, системный акцент в палитре.
7. **Контролы.** Двухцветный фокус, варианты иконок 16/20/24, статусы текстом, точные размеры ComboBox и TextBox.
8. **Отчёт.** Severity-first: вердикт, затем файл, затем статистика и движки.
9. **Доступность.** Копируемые хеши, `forced-colors`, `prefers-reduced-motion`, полная клавиатурная доступность.

## 5. Рассмотренные подходы

### 5.1 Фон окна

- **A. Оставить CSS-градиент.** Дёшево, но это не Mica; пользователь видит разницу сразу. Отклонено.
- **B. Настоящая Mica через window effects + runtime fallback (выбрано).** Tauri включает `transparent: true`, `shadow: true` и применяет `mica`/`micaDark`/`micaLight` только на build ≥ 22000. На Windows 10 — непрозрачный фон. Риск ограничен настройкой окна.
- **C. Переписать оболочку на WinUI 3 / XAML.** Максимальная достоверность, но это другой стек, другой проект и потеря текущей кодовой базы. Отклонено.

### 5.2 Акцент

- **A. Оставить только фиксированные цвета.** Просто, но не совпадает с системой. Отклонено.
- **B. Добавить `system` и сделать его значением по умолчанию (выбрано).** Пользователь сохраняет возможность выбрать свой цвет; persisted-значения совместимы.
- **C. Только системный акцент, без выбора.** Максимально нативно, но отнимает существующую возможность. Отклонено.

### 5.3 Навигация

- **A. Только CSS media queries.** Просто, но нельзя реализовать оверлей и клавиатурную модель без дублирования логики.
- **B. JS-модель режимов + чистые функции + CSS-классы (выбрано).** Режим вычисляется по ширине, тестируется юнит-тестами, CSS отвечает только за вид.
- **C. Фиксированная панель.** Не соответствует NavigationView. Отклонено.

### 5.4 Списки и настройки

- **A. Оставить отдельные карточки.** Привычно для веба, но не для WinUI.
- **B. Один surface + разделители; заголовки секций вне карточек (выбрано).** Совпадает с ListView и «Параметрами».

## 6. Границы

**Не входит в эту работу:**

- Переписывание UI на XAML/WinUI 3.
- Acrylic на всех поверхностях; используется только Mica как фон окна и Acrylic-подобные flyout-токены.
- Snap Layouts по наведению на «Развернуть» — требует subclassing оконной процедуры; вынесено в отдельную задачу после приёмки.
- Изменение логики сканирования, VirusTotal, keychain, трея и уведомлений.
- Новая схема persisted state; `accent: 'system'` обратно совместим.
- Отдельный titlebar для macOS/Linux; базовая конфигурация остаётся непрозрачной.

## 7. Ограничения

- Windows 10 должна оставаться полностью рабочей: Mica — прогрессивное улучшение.
- Все 7 локалей (`en`, `ru`, `es`, `de`, `fr`, `pt`, `zh`) получают новые строки.
- Направление импортов: `features → core | app | components`; `components` не импортирует features.
- Новые Tauri-команды: Rust-модуль → `lib.rs` → `api.ts` → хук/`App.tsx`.
- Никаких `any` в новом TypeScript; чистые функции тестируются.
- Секреты не попадают в логи, состояние и отчёты.
- Версия поднимается до 0.5.0, CHANGELOG, AGENTS.md и CLAUDE.md обновляются.

## 8. Критерии приёмки

1. На Windows 11 22H2+ видна Mica; на Windows 10 интерфейс непрозрачный, без просвета рабочего стола.
2. `system` — акцент по умолчанию; смена акцента в Windows применяется после возврата фокуса; текст на акценте контрастен.
3. В заголовке есть кнопка навигации, restore при максимизации, «назад» на отчёте, приглушение в неактивном окне и подсказки.
4. Панель: 320 px при ≥ 1008, 48 px при 641–1007, оверлей при ≤ 640; работают стрелки, Home/End.
5. Статусы — цветной текст; строки списка собраны в один surface с разделителями.
6. Настройки: заголовки секций над карточками, строки 64 px, без флагов.
7. Двухцветный фокус виден на кнопках, полях, переключателях, вкладках и опциях списка.
8. Иконки используют варианты 16/20/24; `clock` больше не подменяется.
9. Отчёт начинается с вердикта и количества детекций.
10. `npm run build`, `npm run lint`, `npm run format:check`, `npm run check:versions`, `npm test`, `cargo check` и `cargo test` проходят; версия 0.5.0.

## 9. Риски

| Риск                                               | Снижение                                                                   |
| -------------------------------------------------- | -------------------------------------------------------------------------- |
| Mica не поддерживается (Win10, RDP, VM)            | `get_window_backdrop` по build number; solid fallback с непрозрачным фоном |
| `UISettings` не инициализируется на потоке команды | Fallback на `HKCU\...\DWM\ColorizationColor`                               |
| Платформенный конфиг Tauri заменяет массив окон    | В `tauri.windows.conf.json` дублируется полный объект окна                 |
| `visible: false` и окно не показывается            | Показ в `finally` после hydration, с проверкой `startMinimized`            |
| Экстремальный системный акцент                     | Расчёт `onAccentFor` по контрасту, юнит-тесты на белом/чёрном              |
| Слишком узкое окно                                 | `minWidth: 560`, оверлей и проверка на 600/640 px                          |
